## OCPP

OCPP (Open Charge Point Protocol) is published by the [Open Charge Alliance](https://openchargealliance.org/).
SME OCPPSim is an independent implementation based on the publicly available specification documents.

- SME OCPPSim is **not OCA certified** and has **not been tested with OCTT** (the OCA compliance test tool).
- The official OCA JSON schemas are **not bundled**; the message models are written for this project.
- ISO 15118 / Plug & Charge is **not supported** (the standard is not freely available).

"OCPP" and "Open Charge Alliance" are used only to describe the protocol; this project is not affiliated with
or endorsed by the Open Charge Alliance.
